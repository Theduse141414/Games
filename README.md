# Games

## Pong

Ein klassisches Pong-Spiel im Browser – eine einzelne HTML-Datei, keine Abhängigkeiten.

**Starten:** `pong/index.html` im Browser öffnen.

- **1 Spieler** gegen den Computer (Schwierigkeit: leicht / mittel / schwer)
  – Steuerung: `W`/`S`, Pfeiltasten oder Maus/Touch
- **2 Spieler** an einer Tastatur – Spieler 1: `W`/`S`, Spieler 2: `↑`/`↓`
- `P` / `Esc` = Pause, `F` oder der Button oben rechts = Vollbild, wer zuerst 7 Punkte hat, gewinnt
- Der Ball wird mit jedem Treffer schneller; der Abprallwinkel hängt davon ab, wo er den Schläger trifft.
